Why this module

The engine the displays run on.

ROUTING

Queryable routing

First class rules route each product to a board and lane by point of sale, category or attribute, so you can answer which station makes what.

TRUTH

Append only audit

Card state is the projection of a durable event log, so concurrent bumps are ordered by the server and nothing is lost to a clock skew.

COMMUNITY

No Enterprise needed

Builds on the standard Point of Sale and bus modules and installs on a clean Odoo Community.

What is inside

Built to do the job, end to end.

  • Boards and lanes. Configurable display boards, each with its own lanes and routing.
  • Tickets, items and cards. An original model where each card is the unit staff bump.
  • Realtime push. A private per board channel keyed by a secure token.

Honest about the edges

What this does not do, so nothing surprises you.

  • This is a backend dependency. The screens live in the Kitchen Display and Order Status Screen modules.
  • Restaurant coursing and self order kiosk routing are planned for later releases.
